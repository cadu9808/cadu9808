onde eu mando esse readme

O README do perfil vai em um repositório especial no GitHub. Passo a passo:

Acesse github.com e clique no + (canto superior direito) > New repository.
No campo Repository name, digite exatamente o seu nome de usuário do GitHub (por exemplo, se seu usuário é carlosatner, o repositório deve se chamar carlosatner). O GitHub mostra uma mensagem avisando que é um repositório especial.
Marque como Public.
Marque a opção Add a README file e clique em Create repository.
Abra o README.md que foi criado, clique no ícone de lápis (editar), cole o texto e clique em Commit changes.

Pronto: o conteúdo aparece automaticamente na página inicial do seu perfil.

Já a bio curta (a de 160 caracteres) vai em outro lugar: na página do seu perfil, clique em Edit profile e cole no campo Bio.

Se você já tiver um repositório com o nome do seu usuário, é só editar o README dele.
